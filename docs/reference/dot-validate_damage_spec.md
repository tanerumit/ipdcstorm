# Validate and fill damage specification defaults

Validate and fill damage specification defaults

## Usage

``` r
.validate_damage_spec(damage)
```

## Arguments

- damage:

  Named list supplied to
  [`generate_daily_hazard_impact_spatial()`](https://tanerumit.github.io/ipdcstorm/reference/generate_daily_hazard_impact_spatial.md).

## Value

Named list with validated method-specific defaults filled in.
